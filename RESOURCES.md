# F# Resources

## Knowledge

- [Microsoft Learn: F# documentation](https://learn.microsoft.com/en-us/dotnet/fsharp/)
  Official language reference and tour. Use for: syntax, records, unions, pattern matching, and checking any claim in a lesson.
- [Microsoft Learn: A tour of F#](https://learn.microsoft.com/en-us/dotnet/fsharp/tour)
  Fast overview with runnable snippets. Use for: first exposure to each construct.
- [F# for Fun and Profit by Scott Wlaschin](https://fsharpforfunandprofit.com/)
  Well-regarded practical series on F# for business software. Use for: domain modeling with types, functional thinking.

## Wisdom (Communities)

- [F# Software Foundation community forum](https://forums.fsharp.org/)
  Official forum; slower than chat. Use for: longer questions, design critique.
- [F# on Slack](https://fsharp.org/guides/slack/)
  Foundation Slack; its guide points to the F# Discord when history matters. Use for: quick questions.
- F# Discord (listed on fsharp.org, unaffiliated with the Foundation)
  Use for: real-time help and code review.
