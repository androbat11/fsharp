F# Glossary

Grows with each lesson.

Lesson 1

dotnet fsi
F# Interactive, a REPL. End input with ;; to run it.
//
Line comment.
= and %
In let, "is defined as"; elsewhere, equality. % is remainder.
let
Binds a name to a value or function. The binding is immutable.
Expression
Code that produces a value. F# code is almost all expressions; the last one in a function is its result.
Type inference
The compiler works out types without annotations.
Partial application
Supplying fewer arguments than a function takes, giving back a new function (add 10).
Pipeline |>
x |> f is f x, written so data reads left to right.
Lambda fun x -> ...
An anonymous inline function.

Lesson 2

type
Declares a new type.
Record
A named bundle of fields: { Name: string; Age: int }. All fields exist at once. Immutable.
{ r with F = v }
Copy of record r with field F changed.
Discriminated union
A value that is exactly one of several cases, each optionally carrying data: | Cash | Card of string.
match ... with
Tests a value against patterns top to bottom; returns the first matching branch.
_ (wildcard)
Matches anything, ignores it.
Incomplete match (FS0025)
Compiler warning that a match misses a case.
